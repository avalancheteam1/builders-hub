Welcome. By the end of this workshop you will have deployed a real smart contract to a real blockchain, and you will own a token that carries whatever name you give it.

No prior blockchain experience is needed. You do not need to install a code editor, a compiler, or a command line tool. Everything happens in this browser tab.

## What You Will Build

An **ERC-20 token** — the same standard behind USDC, and behind most tokens you have heard of. You choose three things:

- **The name**, for example `Avalanche Workshop Token`
- **The symbol**, for example `AWT`
- **The supply**, for example one million tokens

Then you press a button, sign a transaction, and your token exists on the Fuji network. You will be able to look it up on a block explorer and see it sitting in your wallet, exactly like any other token.

## How Long It Takes

About 45 minutes, in five steps:

| Step | What happens |
| --- | --- |
| Set up a wallet | Install Core and create an account |
| Switch to Fuji | Point your wallet at Avalanche's test network |
| Get test AVAX | Claim free tokens to pay the network fee |
| Deploy your token | Fill in three fields and press Deploy |
| Verify and share | Find your contract on the explorer, add it to your wallet |

## A Note on Real Money

Everything in this workshop happens on **Fuji**, Avalanche's test network. The AVAX you claim is free and has no value, and the token you deploy has no value either. Nothing here can cost you money.

That is the point of a testnet: it behaves exactly like the real network, so you can make mistakes freely. The same steps on the real network are identical — only the network you are connected to changes.
